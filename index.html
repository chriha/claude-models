Spec sheet

Sources. Prices, context, max output, effort defaults: Anthropic API model table (checked 2026-11-04). Benchmarks & speed: third-party write-ups and trackers, so treat as approximate — DeepLearning.AI, Artificial Analysis, OpenRouter, ComputingForGeeks. GPQA numbers are OpenRouter's own runs, not Anthropic's. Speed is output tokens/s (Haiku: reported 237, one independent test saw 183; Sonnet/Opus measured at max effort).

My assumptions (est). Benchmarks are shown as published, with no per-effort scores found, so the effort toggle only changes thinking-token spend, cost and latency, not accuracy. Lower effort usually trades a little quality for fewer tokens — verify on your own tasks. Task recommendations are opinion.
